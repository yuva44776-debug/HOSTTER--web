# HOSTTER Apparels - React Version

A modern React conversion of the HOSTTER Apparels website with all original HTML and CSS content preserved.

## Project Structure

```
src/
├── components/
│   ├── Loader.js
│   ├── Navbar.js
│   ├── Hero.js
│   ├── AboutSection.js
│   ├── Features.js
│   ├── WhySection.js
│   ├── ProductsSection.js
│   ├── CategorySection.js
│   └── ContactSection.js
├── styles/
│   └── index.css
├── App.js
└── index.js

public/
├── index.html
├── images/
└── video/
```

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Build for production:
```bash
npm run build
```
